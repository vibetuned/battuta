# Add measure

A gray measure with a **+** in the middle of the staff, after the last
measure of the score in edit view. Tap it and a measure is added at the end,
empty like its neighbour, and the caret goes there. No keyboard needed — made
for writing with the stylus, where reaching for ⊞+ breaks the flow; a
finger, a mouse or the pen itself presses it.

The editor also adds a measure by itself when a note entered from the
keyboard or MIDI lands on the last event of the score (the writing flows
on); this tile is for the pen, which writes where it touches.

## Turning it on and off

battuta menu → 🌣 shortcuts → **plugins** → *Add measure*. Off takes the
tile away. On by default.

## Keys

None. The tile is the whole interface.

## Settings and storage

| Key | Where | Meaning |
| --- | --- | --- |
| — | settings | nothing |
| — | storage | nothing |

## What it does not do

- **No measure inside the score**: it adds at the end only. ⊞+ on the
  keyboard inserts after the caret's measure.
- **Not in page view**, where there are no measure tiles.
- **Not on an empty score**: the new measure is shaped like its neighbour,
  so there must be one.

## Guide

Adding a measure is one tap; undo (⌘Z) takes it back.
