# Screencast keys

Shows what you press while you work, in the window's bottom-left corner,
for video demos and screenshots, like Blender's Screencast Keys add-on:

- **keys**, modifiers first, with the action they ran: `Ctrl Z · undo`,
  `T · tie`, `Shift A · chord a`, `← · nav left`. A key that ran nothing
  shows alone, and a key held or pressed again in a row counts up
  (`→ ×4 · nav right`).
- **MIDI notes** you play, from any instrument and from the on-screen
  piano: `♪ C4`, and notes struck together as one chord, `♪ C4 E4 G4`.

Each line fades a few seconds after it last changed; the last six stay
on screen. Nothing it shows takes a click or a touch: the score
underneath works as always.

## Turning it on and off

It is **off until you turn it on**: battuta menu → 🌣 shortcuts →
**plugins** → *Screencast keys*. It appears at once, and the switch is
remembered — turn it off again after recording.

## Keys

None of its own: it only shows the keys you press. Keys typed into a text
field (a title, a lyric) are never shown, and neither are the on-screen
keyboard's buttons.

## What it does not do

- **No mouse clicks** or stylus strokes: keys and notes only.
- **No placement or size settings** yet: bottom-left, a fixed size made
  to be read in a video.
