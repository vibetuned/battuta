## 0.0.3 — 2026-09-12

A quality-of-life round: ten requests from the first release users, plus two
fixes that fell out of testing them.

### Writing music

- **Lyrics** under the notes: <kbd>l</kbd> opens the lane, space or enter
  commits a syllable and jumps to the next note, <kbd>-</kbd> hyphenates a
  word across notes. [Lyrics →](../../guide/harmony/#lyrics)
- **Repeats work in note input** — they moved to <kbd>alt</kbd> +
  <kbd>r</kbd>, so closing a section no longer means leaving input mode. With
  nothing selected it puts an **end repeat** on the caret's measure, and
  playback loops it. [Repeats →](../../guide/form/#repeat-barlines)
- **Group staves** with <kbd>shift</kbd> + <kbd>G</kbd> over a block: none →
  brace → bracket, barlines following the symbol.
  [Staff groups →](../../guide/structure/#grouping-staves)
- **Numpad 0 writes a rest**, completing the numpad's duration row, and
  **picking a duration now clears the dot** — a new value starts plain,
  whether you change it with the digits or with <kbd>alt</kbd> + arrows.
- **6/4** joined the meter list.

### Playing

- **Play through your MIDI devices**: tick **MIDI** in the player row and
  playback goes to every connected output instead of the built-in piano —
  the same performance, with repeats, ties and articulations. On macOS and
  Linux battuta also appears as a MIDI source of its own, so listener apps
  hear it. [Playback →](../../guide/playback/#playing-through-midi-devices)
- **Transpose the MIDI** by ±12 semitones, live, applying to the
  playback-MIDI export too. The written score and the built-in piano stay at
  pitch.

### Getting around

- **The context bar is keyboard-drivable**: <kbd>F6</kbd> focuses it, arrows
  move and change values, <kbd>esc</kbd> returns to the score.
  [Status bar →](../../reference/status-bar/#driving-the-bar-from-the-keyboard)

### Fixes

- **Dialogs that never appeared in the desktop app now do** — the unsaved-work
  warning when closing a tab, the paste-differences question and the
  overwrite guard were all silently answering "no" for themselves.
- **Page view no longer clips** braces and brackets at the left edge; pages
  render with proper margins.
- **macOS: <kbd>alt</kbd> shortcuts work** (auto-beam among them) — Option
  composes letters into symbols there, which battuta was not accounting for.

## 0.0.2 — 2026-08-30

Validated on all three platforms, and the first release with signed macOS
builds and one-command installs (Homebrew, apt).

### The score's own tempo

- **A ♩= tempo button** beside the title sets the score tempo in the MEI
  (`@midi.bpm`): page view prints the marking, playback runs at it, and the
  speed select now reads **× the score tempo**.
  [Playback →](../../guide/playback/)

### Touch: the on-screen keyboard

- **A virtual keyboard** for tablets (🎹, automatic on touch screens): a
  two-octave piano with **multi-touch chords** and an octave rail, sticky
  ctrl/alt/shift latches, a four-way digit pad, and one key per action —
  generated from your live keymap, so rebinds and new actions appear on their
  own. Keys **relabel live** under a latch to show what they will do.
  [The on-screen keyboard →](../../guide/virtual-keyboard/)

### Import & export

- **Import everything Verovio reads**: MusicXML (plain and `.mxl`), ABC,
  Plaine & Easie and Humdrum kern all open — converted to MEI on open, as a
  new unsaved document so your source is never overwritten.
- **Export playback MIDI**: battuta's *performed* form — repeats and jumps
  expanded, tie chains merged, staccato/legato gates — as a `.mid`.
- **Export written-score MIDI, SVG pages, Humdrum kern and Plaine & Easie**
  from the battuta menu. [Files →](../../guide/files/#formats)

### Safety

- **Session restore**: the open tabs persist after every edit and come back on
  the next start — a crash or window close loses at most a second of work.
- **Close confirmation** on dirty tabs; clean ones close silently.
- **External-change guard** (desktop): saving a file another program modified
  asks before overwriting. [Files →](../../guide/files/#saving)

### Distribution

- **The macOS app is signed and notarized** (Apple Developer ID) — no more
  Gatekeeper warning — and installable with
  `brew install --cask vibetuned/tap/battuta`.
- **A signed apt repository** at `battuta.vibetuned.com/apt` for
  Debian/Ubuntu. [Install →](../../install/)

### Fixes from the validation round

- **macOS: musical glyphs no longer render as black squares.** macOS ships
  no font for the Musical Symbols Unicode block, so the duration and mark
  glyphs (𝅝 𝅗𝅥 𝄆 𝄇 𝄐 𝄪) were tofu — battuta (and this guide) now bundle a
  small Noto Music subset that fills exactly those characters.
- **Windows: no more doubled MIDI input.** A driver that registers the same
  device as two ports made every note arrive twice; ports are now
  deduplicated by device name on both MIDI paths.

### The header, reorganised

- **Two rows**: tabs and views on top; the score's title, tempo and (in page
  view) the player below. File chores, exports and tools moved into **one menu
  under the battuta name**; the measure buttons retired in favour of numpad
  <kbd>+</kbd> <kbd>−</kbd> <kbd>*</kbd> and the on-screen keyboard.
  [Tour →](../../tour/#the-header)
- **Performance numbers are off by default** everywhere.

### Playback

- **A score player in page view** — ▶ / ⏸ / ⏹, with the sounding note highlighted
  from the same timeline that drives the audio, and the view scrolling to follow.
  [Playback →](../../guide/playback/)
- **Playback follows the form**: repeat barlines, volta sets, and one dal-segno or
  da-capo jump with *fine* and *To Coda*. A mid-score D.C. now stops the first pass
  at the jump instead of running to the end. [Repeats and form →](../../guide/form/)
- **Ties, slurs and articulations shape what you hear** — a tie chain sounds as one
  held attack, staccato shortens, slurred and tenuto notes sound full, unmarked
  notes detach slightly.
- **Tempo and progress**: a 0.5×–2× tempo select that applies live, plus a clickable
  progress bar with an elapsed/total readout.

### Notating the form

- **To Coda** joined the <kbd>o</kbd> cycle, distinguished from the coda sign the way
  MEI does it — by the mark's text.
- **Attack intensity** on <kbd>shift</kbd> + <kbd>i</kbd>: sf → sfz → rinf → rfz.
  [Marks →](../../guide/marks/#dynamics)
- **3/2** joined the meter list.

### Editing

- **Reflection cycle** on <kbd>shift</kbd> + <kbd>r</kbd>: prime → inversion →
  retrograde → retrograde inversion, over a block, with the rhythm held fixed.
  [Arranging →](../../guide/arranging/#serial-forms)
- **Tie chains got smarter** — tying a note that is already tied extends the chain
  instead of orphaning the first tie, and untying a link splits it into valid
  remainders.
- **Cross-staff slurs and hairpins**: shift-clicking across staves selects an
  endpoint pair, which is what those spans need.
  [Selection →](../../guide/selection/#endpoint-pairs-across-staves)
- **One selection model**: shift-runs and mouse blocks now drive every action, each
  action taking the granularity it needs. <kbd>r</kbd> toggles repeats from a
  shift-run; <kbd>ctrl</kbd> + <kbd>c</kbd> copies a run's full measure span.
- **Add staff below places the caret** on the new staff, ready for entry.

### Getting around

- **The view follows the caret** — keyboard navigation and note entry scroll the
  caret back into view instead of leaving you hunting for it.
- **Row navigation**: <kbd>Home</kbd> / <kbd>End</kbd> for the row's start and end,
  <kbd>PageUp</kbd> / <kbd>PageDown</kbd> for the previous and next row, and
  <kbd>Insert</kbd> toggling note input both ways.
  [Navigation →](../../guide/navigation/)

### The application

- **A score title editor** in the header, which page view actually prints.
- **Toasts** for errors, confirmations and refusals — with a `×` to dismiss, and
  selectable text so you can copy an error into a report.
- **A dirty marker** (`*`) on tabs, computed from the undo stack, so undoing back to
  your last save reads as clean again.
- **Dialogs remember the last folder**, including the *open file…* button, which
  used to bypass the native dialog entirely.
- **Separate QWERTY and AZERTY keymaps** with a layout toggle in the shortcut
  editor, and **persisted options** — layout and zoom survive restarts.
  [Keyboard reference →](../keyboard/)
- **macOS fixes**: MIDI hot-plug now works (CoreMIDI needs a run loop pumped), and
  the grey Dock icon is gone — macOS 26 re-themes any icon with transparent
  corners, so the artwork is opaque edge to edge now.
- **AGPL-3.0-only** license, declared in every manifest.

## 0.0.1 — first release

The first packaged release: Linux `.deb` and `.AppImage`, an app icon, and `.mei`
file association, on top of a feature-complete v1 editor — tiled Verovio rendering,
a text-editor caret and selection, reversible commands with byte-identical undo,
keyboard and MIDI note entry, copy/paste with the duration validator, context
editing, articulations and ornaments, voices, voltas, tuplets, harmony lanes and a
rebindable keymap.

battuta is pre-1.0 and moves in feature rounds rather than on a release calendar.
