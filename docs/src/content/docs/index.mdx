battuta opens an MEI file, shows it as engraved notation, and lets you move a
caret through it. Arrow keys walk the notes. <kbd>i</kbd> starts typing music.
<kbd>ctrl</kbd> + <kbd>z</kbd> takes any of it back — byte for byte, down to
the last attribute of the file on disk.

It is not an engraver. [Verovio](https://www.verovio.org/) draws every note,
and the document you opened is the thing you are editing — not a picture of it.
