# excerpts

MEI files the guide's real-score figures are engraved from. They live here,
rather than being referenced from somewhere on the author's disk, so the site
builds on any machine.

| File | Music | Used for |
| --- | --- | --- |
| `schumann-melodie.mei` | Schumann, *Melodie* — Album für die Jugend, op. 68 | `real-score` (measures 1–4) |
| `schumann-soldatenmarsch.mei` | Schumann, *Soldatenmarsch* — op. 68 | `real-block` (measures 1–2) |

The music is public domain; the encodings were made in battuta, which is the
point — these figures show the editor's own output.

Only the measure ranges named above are rendered (Verovio's
`select({ measureRange })`), so replacing a file only changes those figures.
